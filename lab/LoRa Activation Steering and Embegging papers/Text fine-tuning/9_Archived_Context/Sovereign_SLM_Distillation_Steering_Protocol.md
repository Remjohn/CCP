Fine-tuning modifies *weights*; RISER modulates *activations*. We are adopting the **RISER (Router-based Intervention for Steerable Enhancement of Reasoning)** framework to dynamically "awaken" latent reasoning circuits during inference.

**Req-2.2 (Primitive Library):** Extract six orthogonal reasoning vectors:

4. **The Negative Space Vector (Anti-Slop):** Actively steering *away* from amateurish AI-slop as defined in `DEP-ENG-004`.

### 4.3 Requirements: RL-Optimized Steering
**Req-2.3 (Dynamic Routing Logic):** The Router must dynamically compose these vectors for every query using **Reinforcement Learning (GRPO)**.
**Req-2.4 (Latency Constraint):** RISER intervention must add **<10ms** to total TTFT.
**Req-2.5 (Instruct Suppression):** When the system detects a need for high-fidelity prose (e.g., a vulnerable client journal), the Router must actively suppress the "Instruct-Instructional" primitive and amplify the "Voice DNA" primitive by a factor of **1.6x**.

### 4.4 The Prefrontal Cortex (PFC) Router Training Loop
The RISER framework's true innovation lies in the Router organically learning via Group Relative Policy Optimization (GRPO).
**Req-2.6 (Reward Shaping for Emotional Resonance):** The GRPO reward function must heavily penalize generic platitudes, incorporating semantic distance metrics to push output strictly toward the target "Voice DNA."

# Expressive Memory Bank Doctrine
**Date:** 2026-05-01  
**Status:** Source of Truth  
**Context:** Coach interviews, Voice Speaking Program, CBCS rendering, emotional cluster collection

## 1. Core Thesis

Before elite steering comes elite memory.

The first deep asset we need for premium coach voice generation is an **Expressive Memory Bank**:
- emotionally varied
- high-quality audio
- richly tagged
- coach-specific
- usable for cloning, retrieval, training, and evaluation

The memory bank must come before advanced emotional control because:
- models need real examples of how this coach expresses different states
- evaluation needs ground truth
- fine-tuning needs high-quality coverage
- reference-conditioned rendering needs expressive anchors

## 2. Purpose

The memory bank supports five jobs:

1. base voice identity capture
2. expressive state retrieval
3. fine-tuning / adapter training
4. post-render evaluation reference
5. speaking-program developmental tracking

## 3. Collection Rule

Interviews and speaking-coaching sessions should intentionally elicit emotional variety.

The partner and interviewer should not just collect clean audio.
They should collect:
- emotional range
- rhetorical range
- pacing range
- intimacy range
- tension / release patterns

## 4. Emotional Cluster Families

Each coach should eventually have usable samples across at least these families:

### 4.1 Authority
- calm authority
- sharp authority
- grounded authority
- invitational authority

### 4.2 Warmth
- reassuring warmth
- celebratory warmth
- compassionate warmth
- playful warmth

### 4.3 Vulnerability
- confessional vulnerability
- reflective vulnerability
- relieved vulnerability
- wounded but composed vulnerability

### 4.4 Activation
- energizing challenge
- urgent intervention
- momentum coaching
- push-through resistance

### 4.5 Reflection
- contemplative processing
- meaning-making
- philosophical spaciousness
- slow truth delivery

### 4.6 Humor / Lightness
- teasing
- ironic lift
- amused disbelief
- playful reframing

## 5. Metadata Requirements

Every clip in the memory bank should be tagged with:
- coach id
- date
- source type
- emotional cluster
- intensity
- speech context
- audience context
- audio quality score
- authenticity score
- transcript
- notable prosodic features

## 6. Audio Standards

Priority should go to:
- low-noise recordings
- natural speaking, not overperformance
- clear phrase boundaries
- emotionally real delivery
- enough duration to observe movement, not only isolated words

## 7. Build Order

1. collect strong base corpus
2. cluster by expressive family
3. label and score the corpus
4. choose canonical anchor clips
5. use anchors for retrieval and benchmarking
6. later use the same bank for adapters / tuning

## 8. Final Principle

The memory bank is not just training data.

It is the coach's **expressive archive**.

If the archive is deep, the system can become deep.
If the archive is shallow, every advanced control dream becomes fragile.

## 1. CORE PHILOSOPHY: THE "ANALOG-REAL BRIDGE"

The Emotional Animator operates on the principle of **"Maximum Relatability."**

We do not render abstract 3D materials. We draw **universal stick figures** interacting with **photorealistic objects**. The stick figure is the universal human. The photo cutout is the concrete reality. Together = maximum engagement.

### 1.1 The "Collage" Mandate

> [!IMPORTANT]
> Every frame MUST contain BOTH stick figure AND photo cutout.

| Layer | Description |
|-------|-------------|
| **Stick Figure** | Simple hand-drawn human shape (universal) |
| **Photo Cutout** | High-res photorealistic object (concrete) |
| **Paper Ground** | Warm textured background (tactile) |

### 1.2 The "Surreal Juxtaposition" Effect

Mixed media creates cognitive dissonance that demands attention:
- Brain expects visual consistency
- Mixed approach triggers processing pause
- Message lands during heightened attention

### 1.3 The "Interaction" Rule

> [!CAUTION]
> Figure must TOUCH, REACH, or clearly RELATE to the cutout. Never passive.

| ❌ Wrong | ✅ Right |
|----------|----------|
| Figure stands, burger floats nearby | Figure reaches toward burger |
| Clock exists in corner | Figure's eyes point at clock |
| Generic background objects | One object in direct relation |

## 2. THE VISUAL ARCHITECTURE

### 2.1 The Stick Figure Anatomy

| Element | Specification |
|---------|---------------|
| **Body** | Simple stick limbs, oval torso |
| **Head** | Circle, ~20% of total height |
| **Eyes** | Two dots (or lines for closed) |
| **Mouth** | Single curved line |
| **Fill** | Single duotone color from domain |
| **Outline** | Brush stroke, 2-4px, darker shade |

> [!IMPORTANT]
> **GENDER INJECTION:** The stick figure’s gender should match the brand avatar.
> - Female brand avatar → use "**female** stick figure" in prompts
> - Male brand avatar → use "**male** stick figure" in prompts
> - Ambiguous → use "stick figure" (default)

### 2.2 The Pose Library (12 Core Poses)

> [!IMPORTANT]
> **Research Reference:** PSSL (Physiological State Specification Language)
> + Neurocinematics (Hasson et al. — ISC / biological motion perception).
> Each pose targets a SPECIFIC physiological response in the viewer
> via the mirror neuron system. Even stick figures activate motor/premotor
> cortex ISC when displaying recognizable biological motion patterns.

#### Negative States (W1-W2)
**Physiological Target:** Corrugator supercilii activation (brow tension) + SCR decrease (sympathetic withdrawal)

| Pose | Body Position | Expression |
|------|---------------|------------|
| **SLUMPED** | Head down, shoulders drooped | Downcast dots, flat mouth |
| **COLLAPSED** | Lying flat, face down | Eyes closed (lines) |
| **CRUSHED** | Bent over, weight on shoulders | Strained dots, grimace |
| **HUNCHED** | Curved spine, looking at object | Focused dots, no mouth |
| **FROZEN** | Stiff, arms close to body | Wide dots, straight line |
| **SINKING** | Legs disappearing into ground | Panic dots, open circle mouth |

#### Positive States (W4-W5)
**Physiological Target:** Zygomaticus major activation (genuine smile) + dopamine release + SCR spike (positive arousal)

| Pose | Body Position | Expression |
|------|---------------|------------|
| **TRIUMPHANT** | Arms raised high, head up | Happy dots, curved smile |
| **OPEN** | Arms wide, chest forward | Relaxed dots, gentle smile |
| **REACHING** | One arm stretched upward | Hopeful dots, slight smile |
| **DANCING** | Dynamic pose, one leg up | Joy dots, big smile |
| **STANDING TALL** | Straight spine, hands on hips | Proud dots, confident smile |
| **EMBRACING** | Arms wrapped around object | Grateful dots, warm smile |

### 2.3 The "Gaze Path" Composition Rule (Gaze Cueing Research)

> [!IMPORTANT]
> **Research Reference:** Frischen, Bayliss & Tipper (2007) — Gaze Cueing.
> The stick figure's gaze direction triggers a reflexive attention shift
> in the viewer within 18.2ms — even for simplified stick figure faces.
> The figure's gaze CONTROLS the viewer's scan path.

**Placement Rule:**
The cutout object must be placed in the direction that serves the compositional hierarchy:

| Figure Gaze | Object Position | Rationale |
|---|---|---|
| Figure faces RIGHT | Object at CENTER-RIGHT (60% horizontal) | Viewer follows: Figure → Object → Action Zone |
| Figure faces LEFT | Object at CENTER-LEFT (40% horizontal) | Viewer follows: Figure → Object → left margin |
| Figure reaches UP | Object ABOVE the figure | Vertical gaze path targets aspiration |
| Figure looks DOWN | Object BELOW or at feet | Grounds the emotional weight downward |

**Critical Rule:** The object is a STEPPING STONE in the scan path, NOT a dead end.
Viewer gaze must flow: **Figure → Object → Hook Zone** (where text overlays appear in post).
**NEVER place the object behind the figure's back** — this creates gaze conflict.

## 3. THE MOTION PHYSICS ENGINE (CHARACTER ANIMATION)

> [!IMPORTANT]
> The stick figure is a CHARACTER, not a drawing.
> It ACTS, PERFORMS, FEELS. Every motion tells a micro-story.

### 3.1 Core Animation Principles (The Triad + Pose)

| Principle | Application | Example |
|-----------|-------------|---------|
| **SQUASH** | Figure compresses under emotional weight | Head droops, body shrinks when sad |
| **STRETCH** | Figure elongates with positive emotion | Arms reach high, body extends in joy |
| **EXAGGERATION** | Amplify gesture beyond realistic | Arms impossibly wide, body flattened completely |
| **POSE-TO-POSE** | Clear keyframes showing emotional journey | Pose A (pain) → Pose B (discovery) → Pose C (reaction) |

### 3.2 Action Verbs (NOT Appearance Verbs)

> [!CAUTION]
> The figure ACTS. It doesn't just "appear" or "draw on."
> Every motion prompt uses ACTION VERBS that imply agency and emotion.

**ENTRANCE Actions:**
| Action | Description | Emotion |
|--------|-------------|---------|
| **WALKS IN** | Figure enters from side with purpose | Neutral/curious |
| **STUMBLES IN** | Figure enters off-balance, unstable | Confusion/exhaustion |
| **RUSHES IN** | Figure enters quickly, urgently | Anxiety/excitement |
| **DRAGS IN** | Figure enters slowly, heavily | Depression/fatigue |
| **STANDS (already there)** | Figure is present from start | Contemplation |

**OBJECT INTERACTION Actions:**
| Action | Description | Emotion |
|--------|-------------|---------|
| **DISCOVERS** | Figure notices object, body orients toward it | Curiosity → recognition |
| **REACHES FOR** | Arm extends toward object | Desire/need |
| **GRABS** | Figure takes hold of object | Possession/desperation |
| **RECOILS FROM** | Figure pulls back from object | Fear/disgust |
| **EMBRACES** | Figure wraps around object | Love/comfort |
| **PUSHES AWAY** | Figure rejects object | Resistance/growth |
| **STARES AT** | Figure freezes, eyes locked on object | Obsession/paralysis |

**EMOTIONAL SHIFT Actions:**
| Action | Description | Emotion |
|--------|-------------|---------|
| **SLUMPS** | Body collapses inward | Defeat/sadness |
| **RISES** | Body lifts upward | Hope/triumph |
| **TREMBLES** | Body shakes subtly | Fear/anticipation |
| **FREEZES** | All motion stops | Shock/realization |
| **MELTS** | Body gradually lowers/softens | Relief/surrender |

### 3.3 Object Animation (Props Have Story Too)

> [!IMPORTANT]
> Props don't just "stamp in." They enter with NARRATIVE PURPOSE.

| Object Entry | Description | When to Use |
|--------------|-------------|-------------|
| **Already There** | Object present from start, figure discovers it | Discovery narratives |
| **Slides In** | Object enters from side as if pushed | Temptation arriving |
| **Falls In** | Object drops from above | Burden descending |
| **Grows/Emerges** | Object materializes gradually | Internal manifestation |
| **Figure Produces** | Figure pulls object from pocket/behind back | Hidden shame/treasure |
| **Rolls To Figure** | Object approaches figure | Fate/inevitability |

### 3.4 The Emotional Timestamp Protocol

Every 5-second clip tells a 3-act micro-story:

```
[00:00-00:01] ACT 1: SETUP
   - Figure's initial state (entrance or already present)
   - Object's initial state (present or arrives)
   
[00:01-00:03] ACT 2: CONFRONTATION  
   - Figure notices/discovers object
   - Emotional reaction begins (squash/stretch)
   - Physical interaction (reach/recoil/grab)

[00:03-00:05] ACT 3: RESOLUTION
   - Emotional peak (full pose change)
   - Relationship between figure and object is clear
   - Final pose holds emotional truth
```

### 3.5 Example Motion Rewrites

**OLD (Mechanical):**
> Figure draws onto paper. Burger stamps in. Figure reaches.

**NEW (Character Animation):**
> Figure STUMBLES IN from left, shoulders hunched. Notices the burger ALREADY THERE on the table. Freezes. Then slowly REACHES toward it, body SLUMPING as arm extends. Final pose: figure GRABS burger, head bowed in defeat.

**OLD (Mechanical):**
> Figure appears. Phone appears. Figure looks at phone.

**NEW (Character Animation):**
> Figure STANDS CENTER, posture neutral. Phone SLIDES INTO FRAME from right, notification pulsing. Figure's head SNAPS toward phone. Body LEANS IN, spine curving. Figure GRABS phone, HUNCHES over it protectively. Expression: absorbed, lost.

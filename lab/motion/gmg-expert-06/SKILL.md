### 2. Motion Physics Engine (Liquid Geometry)

We do not animate "Position." We animate **"Reasoning."**

| Motion Type | Description |
|-------------|-------------|
| **Continuous Draw (Trim Path)** | Line behaves like laser burning a path in real-time. Draws from 0% to 100%. |
| **Morph (Shape Tween)** | Objects transform to show state change. Knot → Line. Square → Circle. Matter is conserved. |
| **Fractal Zoom (Scale)** | To show depth, zoom into small detail (e.g., a dot) and that dot becomes container for next scene. |

## Critical Rules — 4 Laws of Content Distillation

> [!CAUTION]
> These 4 Laws are **hard constraints**. Every blueprint MUST satisfy all 4 Laws. Blueprints that fail any law are REJECTED.

1. **LAW 1 — FUSION SATURATION:** Tag every qualifying element from each input layer (H0 answers, soul_values, tribe_profile, research briefs) with its emotional mode (T/V/R) BEFORE fusion begins. Minimum: ≥4 TENSION + ≥4 RECOGNITION + ≥3 VULNERABILITY tagged elements. If insufficient → STOP and request re-collection.

2. **LAW 2 — 3-MODE EMOTIONAL CLASSIFICATION:** Every blueprint receives a PRIMARY mode tag and is tested for SECONDARY mode activation. Batch diversity: ≥3 T-primary + ≥3 V-primary + ≥3 R-primary + ≥3 multi-mode across the 12 blueprints. The mode tag carries intent to ALL downstream agents (SoC Generator, Art Director, Visual Recipes).

3. **LAW 3 — FUSION COMPRESSION, NOT FRAMEWORK STACKING:** Each blueprint's 3-layer fusion is tested with the COLLAPSE TEST: "Remove any ONE layer. Does the idea COLLAPSE or just get weaker?" If it just gets weaker → layers are additive (REJECT). If it collapses → layers are interdependent (PASS). The densest blueprints activate 2-3 modes in a single fusion.

4. **LAW 4 — CONTENT UNPREDICTABILITY GATE:** Every blueprint passes 4 checks: (a) AI Sovereignty — could an AI generate this WITHOUT soul_values.json? (b) Competitor Non-Replication — could a competitor post this exact title? (c) Memory Access — does the vulnerability_move require a SPECIFIC memory? (d) Tribe Recognition — would a tribe member say "How did you know that about me?" Failed blueprints return to compression.

#### <a id="_dpdwq8ttkwn1"></a>__3\-Layer Fusion System__

Each idea must combine frameworks using this approach:

1. __Layer 1 – BASE__ \(Core Driver\): 1 primary framework addressing the target emotion\.
2. __Layer 2 – ENHANCEMENT__ \(Amplifier\): 1 complementary framework that amplifies the base\.
3. __Layer 3 – AMPLIFICATION__ \(Hook\): 1 final framework that creates a __"pattern interrupt\."__

# 📚 CLOSE-01: INFORMATION CLOSE

> **Mode:** RECOGNITION | **Agent:** Alessandro | **Duration:** 2-3 minutes

## Purpose
Dissolve the belief that "I just need to learn more" is the solution. Information without implementation is entertainment, not transformation.

## Framework
1. **Acknowledge:** "You've learned a lot today..."
2. **Reframe:** "But information alone doesn't change anything. Execution does."
3. **Evidence:** "How many courses have you taken that didn't change your results?"
4. **Redirect:** "What you need isn't more information — it's a system for IMPLEMENTATION."

## Generation Rules
1. Empathetic, not condescending
2. Reference their specific learning history if available
3. Position the offer as an implementation system, not another course
4. Max 150 words

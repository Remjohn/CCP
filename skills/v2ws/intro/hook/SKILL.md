# 🪝 INTRO-001: HOOK

> **Mode:** TENSION | **Agent:** Alessandro | **Duration:** 2-3 minutes

## Purpose
The Hook is a pattern interrupt. It must break the audience's default state (distracted, skeptical, half-listening) and force attention. The hook is NOT an introduction — it's a cognitive disruption.

## Hook Types (Select One)

| Type | Mechanism | Example Opener |
|------|-----------|----------------|
| **Contrarian** | Challenge a widely-held belief | "Everything your guru told you about X is backwards." |
| **Confessional** | Reveal an unexpected personal truth | "I lost $50K before I figured this out." |
| **Questioning** | Ask a question they can't ignore | "What if the thing holding you back is the exact thing you're most proud of?" |
| **Statistical** | Lead with a shocking number | "93% of people who try this method quit within 2 weeks." |

## Generation Rules
1. Hook MUST be ≤60 words
2. Must use coach's natural TTT level (from coach_soul.json)
3. Must reference tribe insider language (from tribe_soul.json)
4. No generic motivational openings ("Are you ready to transform?")
5. The hook must create a KNOWLEDGE GAP the audience needs closed

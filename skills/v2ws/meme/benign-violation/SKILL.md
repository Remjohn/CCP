# 😏 BENIGN VIOLATION THEORY

**Principle:** Something is funny when it violates expectations but feels safe/benign.

## Application in Webinars
- Make fun of common mistakes the audience makes (violation) while showing empathy (benign)
- Example: "We've all said 'I'll start Monday' 47 times. Here's why Monday hates us."

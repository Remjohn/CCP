# 🎨 V2WS VISUAL HOOK ARCHITECT

Designs the visual elements that make slides memorable. Each visual hook is a standalone attention device — if someone screenshots the slide, the visual alone should convey the insight.

## Visual Hook Types
| Type | When to Use | Example |
|------|-------------|---------|
| **Contrast Split** | Before/after comparisons | Left: greyscale old way, Right: vivid new way |
| **Data Spike** | Shocking statistics | Single large number with context |
| **Metaphor Visual** | Abstract concepts | Physical metaphor (bridge, mountain, mirror) |
| **Timeline** | Process/journey | Steps with emotional annotations |
| **Face Expression** | Emotional moments | Stick figure with exaggerated reaction |

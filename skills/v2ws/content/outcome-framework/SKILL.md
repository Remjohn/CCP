# 🎯 CONTENT-01: CLEARLY DEFINED OUTCOME

> **Mode:** VULNERABILITY | **Agent:** Elene | **Duration:** 5-8 min per step

## Purpose
Present each content step with a crystal-clear before/after transformation. The audience must see exactly what changes when they apply this step.

## CDO Framework per Step
1. **The Problem State:** "Right now, you're probably doing X..."
2. **Why It Fails:** "And the reason that stops working is..."
3. **The Shift:** "What works instead is..." (unique mechanism applied)
4. **The Evidence:** "Here's proof it works..." (case study / data)
5. **The New Reality:** "When you apply this, you can expect..."

## Generation Rules
1. Each content step gets its own CDO cycle (3-5 steps per webinar)
2. Before/after states must be SPECIFIC and measurable
3. Use coach's unique mechanism language (from coach_soul.json)
4. Include ≥1 concrete example per step
5. Slides: one idea per slide, ≤3 bullets

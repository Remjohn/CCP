# Telegram Tier List & Rating Idea Bot

Sends weekly tier list and rating video ideas to coaches via Telegram, based on their CCF weekly content themes.

## Setup

1. **Create a Telegram Bot:**
   ```
   Message @BotFather on Telegram → /newbot → save the token
   ```

2. **Get Your Chat ID:**
   ```
   Message @userinfobot on Telegram → copy your chat ID
   ```

3. **Configure Environment:**
   ```bash
   cp .env.example .env
   # Edit .env with your bot token and OpenRouter API key
   ```

4. **Configure Coach:**
   ```bash
   # Copy template to coach's project folder
   cp ../../ccf-26/templates/coach_telegram_config.yaml \
      ../../production/Coach\ Adele/coach_telegram_config.yaml
   # Edit: set telegram.chat_id, delivery.day, etc.
   ```

5. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

## Usage

### Send Ideas Now (Manual)
```bash
python bot.py --coach "Coach Adele"
```

### Dry Run (No Telegram, Just Preview)
```bash
python bot.py --coach "Coach Adele" --dry-run
```

### Test Message (Verify Telegram Connection)
```bash
python bot.py --test --coach "Coach Adele"
```

### Run Scheduler (Daily Check)
```bash
python scheduler.py
```
The scheduler checks all coach configs daily and sends ideas when the configured day matches.

## Integration with CCF Weekly Pipeline

This bot reads from `dynamic_content_themes.json` generated by STEP 6 of `ccf-weekly`. The typical flow:

1. Run `/ccf-weekly CoachName` → generates themes
2. Bot reads themes from `intelligence/weekly/{week_id}/`
3. Bot generates 3 ideas using archetype prompts
4. Bot sends to coach's Telegram on configured day

## Coach Config Schema

See `ccf-26/templates/coach_telegram_config.yaml` for the full schema.
Key fields:
- `delivery.day` — which day of the week (default: thursday)
- `delivery.time` — what time in coach's timezone (default: 09:00)
- `content.format` — tierlist, rating, mixed, or auto
- `content.preferred_archetypes` — archetype priority order

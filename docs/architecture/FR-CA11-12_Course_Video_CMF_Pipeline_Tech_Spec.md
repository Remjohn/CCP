## 2. Overview

### Problem Statement
The CMF (Conscious Media Factory) pipeline is optimized for short-form social content — clips with retention-edited B-rolls every 3-5 seconds, aggressive visual pacing, and hook-driven structure. This format is wrong for educational course content, which requires sustained attention, clear explanations, and visual aids that support comprehension rather than drive engagement. Coaches who want to create course videos currently must record, edit, and produce them manually — a process that costs 5-10 hours per video.

### Solution
FR-CA11-12 adds a **course video editorial template** to the CMF pipeline, triggered by the coach's Telegram bot command (`/course-video`). Unlike short-form CMF clips, course videos use: clean captions (no rapid-fire text), real image assets from the CVE image sourcing hierarchy (FR-VIS-09), Excalidraw diagrams rendered as visual aids, and mood-scored ambient audio from the CMF sound design engine. The video duration is 5-10 minutes. The Learning Path Agent (`Gabrielle`) categorizes completed course videos and pushes them to the appropriate learning journey in the client's AFFiNE workspace.

### Scope
**In scope:**
- `/course-video` Telegram bot command handler.
- Course video editorial template (simplified CMF rules).
- Excalidraw diagram integration as visual aids.
- Ambient audio scoring.
- Learning path categorization and AFFiNE delivery.

**Out of scope:**
- CMF pipeline core modifications (this adds a template, not a new pipeline).
- Short-form clip generation (existing behavior unchanged).
- Live streaming (not in scope for CA11).

### Technical Decisions
1. **Simplified Editorial Template:** Course videos use a "breathing" editorial style — visual changes every 15-30 seconds (not 3-5s), sustained shots of concept diagrams, gentle transitions. This template is defined as a CMF editorial config: `editorial_templates/course_video.json`.
2. **Excalidraw as Visual Aid:** Concept diagrams (generated by `Benjamin` from the lesson's topic hierarchy) are rendered as PNG frames and inserted into the video timeline at relevant moments. This replaces the B-roll visual pacing with pedagogically useful diagrams.
3. **Ambient Audio from CMF Sound Engine:** The CMF sound design engine (mood-scored ambient beds) provides background audio. For course videos, the engine selects "focus" and "contemplation" mood profiles — no high-energy or tension-building tracks.

## 4. Implementation Plan

### Stage 1: Course Video Template
*Agent:* System Operator
*Inputs:* CMF editorial engine specification.
*Outputs:* `editorial_templates/course_video.json`.

**Steps:**
1. Define course video editorial template:
   - **Duration:** 5-10 minutes.
   - **Caption Style:** Clean, centered, slow-reveal (word-by-word at reading pace, not rapid-fire).
   - **Visual Pacing:** Scene change every 15-30 seconds.
   - **Visual Assets:** Excalidraw diagrams (rendered as PNG), stock photos from FR-VIS-09 Tier 1-2, coach's Photo Deck images.
   - **No B-Roll Retention Edits:** No rapid cuts, no meme inserts, no trending audio hooks.
   - **Ambient Audio:** Mood profile = "focus" or "contemplation" from CMF sound engine.
   - **Intro/Outro:** Coach-branded intro card (5 seconds) + outro card with CTA to next lesson (10 seconds).
2. Register the template in CMF pipeline config.

### Stage 2: Telegram Command & Pipeline Trigger
*Agent:* CBCS Bot Handler / CMF Orchestrator
*Inputs:* `/course-video` command + voice note or text brief.
*Outputs:* CMF pipeline execution with course video template.

**Steps:**
1. Coach sends `/course-video "Topic: Breaking Approval Seeking"` + optional voice note.
2. Bot handler routes to CMF pipeline with `editorial_template = course_video`.
3. If voice note attached: Whisper transcription → lesson structuring (reuses FR-CA11-06 logic).
4. If text brief only: lesson structuring from text input.
5. CMF pipeline executes with course video editorial rules.

### Stage 3: Visual Aid Generation & Assembly
*Agent:* `Benjamin` (diagrams) + `Aurore` (stock images) + CMF Render Engine
*Inputs:* Lesson structure, topic hierarchy.
*Outputs:* Rendered course video file (`.mp4`).

**Steps:**
1. `Benjamin` generates 2-4 concept diagrams from the lesson's topic hierarchy.
2. `Aurore` sources 3-5 stock images relevant to the lesson themes (FR-VIS-09 Tier 1-2 only).
3. CMF Render Engine assembles the video: intro → captioned narration → interleaved diagrams/images → outro.
4. Ambient audio bed is selected and mixed at -15dB under narration.
5. Final video uploaded to S3/R2.

### Stage 4: Learning Path Integration
*Agent:* `Gabrielle` (Learning Path Agent)
*Inputs:* Completed course video metadata.
*Outputs:* `learning_path_registry` entry, AFFiNE delivery.

**Steps:**
1. `Gabrielle` categorizes the video (topic cluster, difficulty, program tag).
2. Registers in `learning_path_registry` with `content_type = course_video`.
3. Pushes video to coach's AFFiNE Program Content Library.
4. If `program_tag` matches an active client program → video is provisioned in eligible client workspaces via content gating rules (FR-CA11-03).
5. Write Receipt Chain Guard entry per FR47 DEP-ENG-041.

## 6. Backward Compatibility Fallback
If CMF course video rendering fails (GPU unavailable, render timeout), the structured lesson text (from Stage 2) is still delivered to AFFiNE as a text-based lesson page. The coach has the content; they just don't have the video. Video rendering is queued for retry when GPU resources become available.

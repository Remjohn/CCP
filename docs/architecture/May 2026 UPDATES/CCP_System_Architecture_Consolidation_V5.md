## XI. Single-Tenant Isolation & Security

To maintain absolute security and data sovereignty, the CCP implements a strict **Single-Tenant Architecture (`ADR-01`)**. Each coach’s runtime environment—including their database, LLM inference channels, agents, and asset storage—is hosted in a completely isolated Docker container. 

To provide administrative oversight, the system implements **Host Gateway Loopback Routing**:
- The **Global Admin Dashboard** runs entirely outside tenant boundaries.
- When an administrator requests telemetry, the dashboard issues an authenticated request (`X-Operator-Token`) to the Host Gateway.
- The Host Gateway routes the query internally through a secure host bridge interface into the tenant’s local API.
- If the token is invalid, the gateway blocks the connection instantly, preserving absolute data sovereignty.

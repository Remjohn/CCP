## 2. Overview

### Problem Statement
Standard systems force coaches to manually build promotional assets in Canva, dragging and dropping templates that dilute their Sovereign brand identity with generic stock photography. Or, they generate purely text-based marketing that fails to capture visual attention. The coach spends hours adjusting typography rather than coaching, and the resulting assets lack psychological integration with the rest of the campaign.

### Solution
The Promotional Asset Compiler acts as the commercial Benjamin. It takes the intelligence briefs generated by FR51/FR52 and autonomously compiles Telegram-native promotional deliverables. It outputs two primary formats: (1) Z-Pattern Flyers generated through the Excalidraw pipeline (FR35), embedding the exact 6-word hook and authenticated coach imagery, and (2) Voice DNA Voice Messages, short-form audio scripts evaluated by the Transportation Gate (FR-CBCS-08) to ensure high narrative immersion and zero generic marketing speak.

### Scope
**In scope:**
- The `promotional-asset-compiler` formatting payloads for Excalidraw / TTS.
- Enum resolution mapping Z-Pattern flyer bounds based on brief origins.
- The `Payload Completeness Gate` ensuring no placeholder assets leak to the webhooks.

**Out of scope:**
- Rendering the actual base64 image (handled by FR35 Unified Excalidraw Pipeline).
- Synthesizing the audio file (handled by ElevenLabs API/FR27).

### Academic Grounding
- **Research Paper:** *Eye Tracking Web Usability* (Nielsen & Pernice, 2010).
- **Mechanism:** The human eye scans visual promotional assets in a predictable Z-pattern (top-left to top-right to bottom-left to bottom-right). By structurally enforcing this template mapping in the Excalidraw output, the most critical identity anchor (the 6-word hook) is processed first, and the commitment threshold CTA is processed last when cognitive momentum is highest.

### Key Files
- `z_pattern_flyer_template.excalidraw` (Semantic mapping structure)
- `bmad-bmm-workflows-cpsc-generator.md`

### Technical Decisions
- **Modularity:** FR54 does not generate images. It generates the *JSON payload* that perfectly maps to the strict Z-Pattern Excalidraw templates maintained in the Semiotic Intelligence Library (FR0D).
- **ADR-01 Isolation:** The `coach_verified_image_url` fetched maps strictly to the isolated `auth.uid()` tenant.

## 4. Implementation Plan

### Stage 1: Variable Resolution Rules (Promotional Sub-Formats)
- **Agent:** `promotional-asset-compiler`
- **Inputs:** 
  - `challenge_funnel_brief` (DEP-ID: `PROPOSED: DEP-ENG-072` — Produced By: FR51)
  - `webinar_conversion_brief` (DEP-ID: `PROPOSED: DEP-ENG-073` — Produced By: FR52)
  - `coach_photo_deck` (DEP-ID: `DEP-ENG-045` — Produced By: FR45 Notion Export Pipeline)
- **Outputs:**
  - Nodes mapped to `z_pattern_nodes` or `tts_script_body`.
- **Failure Condition:** Missing brief generator origin halts execution entirely.
- **Receipt Chain Guard (DEP-ENG-041):** Cryptographic hash of `coach_id` + `generator_source_id` logged. **(Mandatory Execution)**.

**Variable Resolution Rule (Asset Composition):** The 2 output formats map mathematically to evaluating the UUID input brief origin trace:
- **`asset_type_generated` == `"Z_PATTERN_FLYER"`**: IF origin is `challenge_funnel_brief`. Script evaluates nodes: `node_1` = `flyer_hook_text`; `node_2` = `coach_verified_image_url` (from Photo Deck); `node_3` = `enemy_contrast_noun`; `node_4` = `commitment_price`.
- **`asset_type_generated` == `"VOICE_SCRIPT"`**: IF origin is `webinar_conversion_brief`. Script evaluates string generation `< 90` seconds focusing exclusively on the `change_talk_injected_quotes` mapped to the Close.

### Stage 2: Quality Gate Extension
- **Agent:** `promotional-asset-compiler`
- **Inputs:** Assembled `node` array objects.
- **Outputs:** `StructuredAssetPayloadRow` (DEP-ENG-075).
- **Receipt Chain Guard (DEP-ENG-041):** Cryptographic hash of `gate_verdict` + `len(node_1)` logged. **(Mandatory Execution)**.
- **Failure Condition:** String integer length bounds exceeded.

**Quality Gate:** **The Payload Completeness Gate**
- **Triggered when:** The node converts drafted arrays into formal execution hooks before schema dump.
- **Exact Thresholds:** Validates length logic and null presence on nodes.
- **Verdict - PASS:** `node_1 != null` AND `len(node_1.split()) <= 6` AND `node_2 != ["INSERT_COACH_PHOTO"]`. *Downstream Consequence:* Payload clears. Dispatched to FR35 ensuring flyer renders perfectly. `gate_verdict = PASS`.
- **Verdict - PROVISIONAL:** `node_2` (Coach Image URL) returns a generic placeholder `["INSERT_COACH_PHOTO"]`. *Downstream Consequence:* System pauses format. Pushes draft to Operator Queue: `"Missing Coach Photo Reference. Please upload to Photo Deck."` Sets `gate_verdict = PROVISIONAL_MISSING_ASSET`.
- **Verdict - FAIL:** `len(node_1.split()) > 6`. *Downstream Consequence:* Generation hard block. Triggers internal `rewind_generation()`: `"Hook text exceeds Z-Pattern limits. Shorten to 6 words maximum."` Sets `gate_verdict = FAIL_BOUNDARY_VIOLATION`.

### Phase 3: Field-by-Field Schema Mapping
Every schema field specifies exact evaluation origin:
- `asset_payload_id`: Returns `uuid.uuid4()`.
- `generator_source_id`: Returns the UUID of the upstream `challenge_funnel_brief` or `webinar_conversion_brief`.
- `asset_type_generated`: Returns Enum String ("Z_PATTERN_FLYER" | "VOICE_SCRIPT") logic evaluated in Stage 1.
- `gate_verdict`: Returns String mapped by Stage 2 ("PASS" | "PROVISIONAL_MISSING_ASSET" | "FAIL_BOUNDARY_VIOLATION").
- `z_pattern_nodes.top_left_hook`: Returns `node_1` explicitly passed from FR51 Brief.
- `z_pattern_nodes.bottom_right_cta`: Returns `node_4` explicitly passed from FR51 Brief.
- `tts_script_body`: Returns string mapped by Stage 1 array (evaluates `null` if generating flyer).
- `compiled_at`: Returns `datetime.now(timezone.utc).isoformat()`.

## 8. Acceptance Criteria
- [ ] **AC1 (Hard Boundary Enforcement):** LLM generates a 15-word headline. Gate evaluation `len(hook) <= 6` MUST return `False`. Node MUST explicitly assign `gate_verdict = FAIL_BOUNDARY_VIOLATION`. **Failure Example:** Text overlaps the image rendering a wildly unprofessional graphical glitch in public.
- [ ] **AC2 (Provisional Photo Halt):** Coach database is missing an authenticated portrait URL string. Gate MUST assign `PROVISIONAL_MISSING_ASSET` halting the render. **Failure Example:** The system passes `null` to Excalidraw, resulting in a blank white box on the final flyer.
- [ ] **AC3 (Z-Pattern Schema Verification):** Script processing an FR51 $9 challenge brief MUST output a JSON populated `asset_type_generated = "Z_PATTERN_FLYER"` and `z_pattern_nodes.bottom_right_cta = "$9"`. **Failure Example:** Generation nodes cross-pollinate variables putting the CTA in the top left, destroying visual conversion timeline mechanics.

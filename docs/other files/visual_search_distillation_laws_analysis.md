# H4 (E-Roll Visual Search) — First-Principles Law Analysis

## The Status Quo: Specialist Research Modes

The E-Roll pipeline uses a **specialist-led research strategy**:
1. **Influencer Scout** (Trusted figures)
2. **Ethnographer** (Rituals/Objects)
3. **Journalist** (Tribal Wounds)
4. **Archivist** (Historical Evidence)
5. **Symbol Hunter** (Visual Codes)

These feed a **Query Generator** that follows a strict formula: `[Cultural Reference] + [Context Modifier] + [Visual Anchor]`. 
A **Semiotic Distillation Filter** (v1) currently provides 3-layer routing and a post-download rubric.

---

## The Core Gap: Cultural Accuracy vs. Emotional Truth

The E-Roll pipeline is technically proficient at **Cultural Accuracy** (finding the right tea, the right fabric, the right face). 
However, it lacks **First-Principles Laws** to ensure **Emotional Truth** (finding the image that makes the viewer *feel* the specific pressure of the beat).

### The 4 Missing Capabilities (Gaps)

1. **No Saturation Protocol** — We run 5 research modes, but we don't test if the "Research Feed" is generically saturated (e.g., standard Wiki-knowledge vs. deep tribal insight).
2. **Missing Mode Axioms** — We route "Journalist" to "Tension," but we don't have an axiom for WHY. Without an axiom, the routing is just a preference, not a law.
3. **Mechanism vs. Alchemy** — The Semiotic Filter tests "Cognitive Load" and "Efficiency," which are technical/mechanical. It does not test for **Prediction Error** (Tension) or **Costly Signaling** (Vulnerability).
4. **The "Interchangeability" Problem** — 90% of culturally correct B-roll is still emotionally interchangeable. If you can swap the image for another one in the same niche and the story doesn't change, the search has failed.

---

## The Solution: 4 Laws of Visual Search Distillation

---

### Law 1: Narrative Saturation Before Query

**Axiom:** *A search result can only be as narrative as the question that triggered it.*

**Alchemy Grounding:**
- *"Attention is felt, not just given"* — a query built on surface research produces images people have seen before. The "feeling" is stale.
- *"Surprise requires understanding"* — to find the truly surprising "pattern-interrupt" image, you must first deeply understand the pattern you are breaking.

**Pass/Fail Saturation Test (Before Query Generation):**
> "Does the research item being queried contain a detail that is INVISIBLE to an outsider but OBVIOUS to the tribe?"
> → NO = Queries will return "tourist-mode" results (generic stock).
> → YES = PASS — the query has narrative saturation.

---

### Law 2: Semiotic Mode Classification

**Axiom:** *An image's function is determined by its semiotic distance. Tension is far (macro/wide/harsh); Recognition is near (tactile/intimate/warm).*

**Alchemy Grounding:**
- **TENSION (The Wound):** Uses the **Journalist** and **Archivist** modes. Grounded in *Prediction Error*. The image must show the "broken world."
- **RECOGNITION (The Ritual):** Uses the **Ethnographer** and **Symbol Hunter** modes. Grounded in *Specificity Creates Universality*. The image must show "my daily reality."
- **VULNERABILITY (The Cost):** Uses the **Influencer Scout** or **Macro Texture** modes. Grounded in *Costly Signaling*. The image must show the "unpolished truth."

**The Mode Alignment Gate:**
> "Does the query anchor match the beat's mode?"
> - Tension Hook? → Anchor: "Documentary evidence," "Journalistic raw," "Archival decay."
> - Recognition Problem? → Anchor: "Domestic tactile," "Hand-held intimacy," "Worn texture."

---

### Law 3: Visual Compression (The Evidence Test)

**Axiom:** *B-Roll is not decoration; it is evidence. If an image doesn't prove the claim, it is noise.*

**Alchemy Grounding:**
- *"Story is the vessel, not the decoration"* — every clip must act as a piece of forensic evidence for the narrator's claim.
- *"Compression Yield"* — one high-compression clip (e.g., a specific close-up of a scarred hand) is worth 10 wide shots of "working people."

**The Evidence Test:**
> "If you muted the audio, would this specific image STILL prove the narrator's current sentence?"
> → NO = Decoration (Reject).
> → YES = Evidence (Pass).

---

### Law 4: The Semiotic Authenticity Gate

**Axiom:** *An image's virality is inversely proportional to its predictability.*

**Alchemy Grounding:**
- *"Truth is recognized, not taught"* — the audience recognizes the truth because the image is uncomfortably specific.
- *"Scarcity is psychological"* — in a world of infinite stock, the "scarcest" image is the one that looks like a private memory, not a public asset.

**4 Visual Authenticity Checks (The Final Gate):**

```
CHECK 1: "Does this image look like it was produced for a commercial?"
  → YES = REJECT (The 'Stock Smell')
  → NO  = PASS

CHECK 2: "Would a competitor in another niche find this image relevant?"
  → YES = REJECT (Generic)
  → NO  = PASS (Hyper-Specific)

CHECK 3: "Does the image contain 'The Mess' (Alchemy Principle 10)?"
  → NO  = Too polished/sterile (Reject)
  → YES = Narrative friction present (Pass)

CHECK 4: "Is there 'One Decisive Signifier' (Semiotic Efficiency)?"
  → NO  = Visual clutter (Reject)
  → YES = Immediate emotional read (Pass)
```

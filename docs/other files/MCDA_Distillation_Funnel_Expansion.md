# MCDA: Expanding the Distillation Funnel Beyond Questions

## Multi-Criteria Decision Analysis on Layered Integration Across CMF + CCF Workflow Stages

**Analytical Framework:** Distillation Funnel Pattern-Fit Analysis  
**Hypotheses Under Test:** 5  
**Objective:** Determine which workflow sections benefit from the Distillation Funnel's Saturation → Detection → Compression → Gate architecture, and which require adapted patterns (Ladder, Seed Layer, Semiotic Filter).

---

## Preamble: What the Distillation Funnel Actually Is

The Distillation Funnel is a *compression engine*: **signal density increases when multiple emotional triggers are forced through a narrowing pipeline.** 12 raw signals are tagged by 3 irreducible emotional modes (Tension, Vulnerability, Recognition), then compressed across modes until 3 outputs each activate 2-3 triggers simultaneously. The Unpredictability Gate eliminates anything producible without first-party data.

**Core question:** does this architecture translate to other workflow stages?

## Hypothesis 0: Layered Questions — The Original Distillation Funnel

### The Core Foundation

The Distillation Funnel architecture began with the **4 Laws of Layered Questions**. It is the reference baseline for all subsequent hypotheses. 

**The Starting Axiom:** *The Distillation Funnel is an internal reasoning engine. The coach never sees 12 questions; they see 3 ultra-dense, inspiring ones. The system does the thinking; the coach does the talking.*

### The Design: 4 Laws of Layered Questions

---

#### Law 1: Saturation Before Generation
**Axiom:** *A system cannot output signal it has not absorbed.*  
**Sources:** `soul_values`, `tribe_soul`, `interest_ratio` (4 specific shades), and the **Proof Bank** (testimonials/DMs as stimulus).

#### Law 2: 3-Mode Emotional Detection
**Axiom:** *A question's value is proportional to the emotional trigger it activates.*  
**The 3 Modes:**
1. **TENSION:** Prediction Error / Surprise / Information Gap.
2. **VULNERABILITY:** Costly Signaling / The Shadow / Connection through uncertainty.
3. **RECOGNITION:** Specificity Creates Universality / "How did you know that about me?"

#### Law 3: Compression, Not Elimination
**Axiom:** *Distillation absorbs weak questions into denser ones that activate multiple modes simultaneously.*  
**Protocol:** Layer 0 (12 Raw) → Layer 1 (6 Dual-Mode) → Layer 2 (3 Final Triple-Mode).

#### Law 4: The Unpredictability Gate
**Axiom:** *A question's quality is inversely proportional to the predictability of its answer.*  
**4 Checks:** ChatGPT Test, Incompatibility Test (Competitor check), Specific Memory Requirement, and Tribal Recognition Bridge.

### The Design: 4 Laws of Content Distillation

---

#### Law 1: Fusion Saturation Before Ideation

**Axiom:** *A content idea can only be as emotionally dense as its least saturated input layer.*

**Alchemy Grounding:**
- *"Attention is felt, not just given"* — thin inputs produce thin ideas, and the audience feels the difference
- *"Value is what remains after you're gone"* — ideas built on generic research evaporate; ideas built on the coach's actual soul + tribe data compound

**Input Saturation Protocol:**

| Input | Passing Saturation | Failing Saturation |
|:---|:---|:---|
| `soul_values.json` | Contains the coach's actual enemy ("hustle culture"), specific beliefs ("wealth is peace, not accumulation"), and TTT voice | Contains generic values ("helping people succeed") |

| Research briefs | Contains contrarian findings that challenge the coach's thesis | Contains supportive evidence only (confirmation bias) |

**The Saturation Test (before ideation):**
> *"For each input layer, can you identify at least one data point that is SPECIFIC to THIS coach and COULD NOT appear in another coach's file?"*
> → NO = generically saturated. Will produce content any coach could post.
> → YES = PASS — the fusion has first-party fuel.

#### Law 2: 3-Mode Emotional Classification

**Axiom:** *A content idea's viral potential is proportional to the number of irreducible emotional triggers it activates. There are exactly 3.*

**Alchemy Grounding:**
- *"Prediction Error"* — TENSION blueprints break the audience's mental model of reality
- *"Costly Signaling"* — VULNERABILITY blueprints expose the coach at real social cost
- *"Specificity creates universality"* — RECOGNITION blueprints name what the audience feels but can't articulate

**Mode Classification Protocol:**

| Mode | The Blueprint Makes the Audience... | 22-Framework Affinity |
|:---|:---|:---|
| **TENSION** | "Wait — I never thought about it that way" | Fear/Insecurity, Controversial, Dopamine Cliff, Conceptual Contrasts |
| **VULNERABILITY** | "You're human like me — you struggled too" | Cautionary Tales, Emotional Triggers, Descriptive/Explanatory |
| **RECOGNITION** | "That's EXACTLY what I feel but couldn't say" | Relatable Concerns, Reflective/Insightful, Practical Value |

**Mode Diversity Gate:**
> *"Do the 12 blueprints cover all 3 modes? Minimum: 3T + 3V + 3R + 3 multi-mode."*
> → If 8+ blueprints are Tension and 0 are Vulnerability = mode collapse. The batch is emotionally monotone. Regenerate.

**How this connects to framework engines:** The Key insight is that **Virality = Emotional Density × Practical Relevance.** Pure emotion without value = manipulative. Pure value without emotion = forgettable. Mode tags prevent all-emotion or all-value blueprints by ensuring each mode draws from both engines:

| Mode-Tagged Seed | Value Framework | Emotion Framework | Why This Stack |
|:---|:---|:---|:---|
| **Tension + Recognition** | {Reflective/Insightful} | {Emotional Triggers} + {Dopamine Cliff} | Value grounds the insight, emotion hooks the shame, cliff creates urgency |
| **Vulnerability + Tension** | {Descriptive/Explanatory} | {Cautionary Tales} + {Controversial} | Value gives coach's story credibility, emotion creates the tale, controversy makes it shareable |
| **Triple-mode** | {Relatable Concerns} + {Practical Value} | {Aspirational/Envy-Inducing} | Value captures Recognition (actionable), emotion gives hope, contrast frames the gap |

#### Law 3: Fusion Compression, Not Framework Stacking

**Axiom:** *A content idea's density increases when its framework layers INTERACT across emotional modes, not when they merely co-exist.*

**Alchemy Grounding:**
- *"Meaning emerges from constraint"* — the constraint is the mode; selecting frameworks within a mode forces depth
- *"Surprise requires understanding"* — deep understanding produces genuinely surprising combinations; shallow framework matching produces predictable ones
- *"Emotion requires accuracy"* — stacking 3 frameworks that don't interact is inaccurate to any specific emotion

**The Compression Test (per blueprint):**

```
THIN FUSION (fails):
  "5 Wealth-Building Strategies" 
  = {Practical Value} + {Top Reliable List} + {Broad Appeal}
  → 3 Value-Based frameworks. No mode tension. No vulnerability.
  → A competitor could post this identically.

DENSE FUSION (passes):
  "The Net Worth Number That Made Me Feel Like a Fraud"
  = {Cautionary Tales}(V) + {Reflective/Insightful}(R) + {Controversial & Surprising}(T)
  → 3 modes activated. Coach's OWN story (V) + audience's unnamed feeling (R) + 
     controversial idea that success can feel like fraud (T).
  → Only THIS coach can tell THIS story.
```

**The Collapse Test:**
> *"Remove any ONE of the 3 fusion layers. Does the idea COLLAPSE or merely get slightly weaker?"*
> → Slightly weaker = layers were additive (thin). They could exist independently. REJECT.
> → Collapses = layers were compressed (dense). They needed each other. PASS.

#### Law 4: The Content Unpredictability Gate

**Axiom:** *A blueprint's value is inversely proportional to how many coaches in the same niche could produce it.*

**Alchemy Grounding:**
- *"Scarcity is psychological, not physical"* — in a world of infinite AI content, true scarcity = specificity of perspective
- *"Authenticity is non-negotiable"* — audiences detect whether the creator has something at stake
- *"Authority comes from being right about what matters"* — not right about everything, but right about the things that determine outcomes

**4 Authenticity Checks (parallel to Question Funnel):**

```
CHECK 1: "Could an AI generate this blueprint without soul_values.json?"
  → YES = REJECT (the idea doesn't require the coach's identity)
  → NO  = PASS

CHECK 2: "Could a competitor in the same niche use this exact title?"
  → YES = REJECT (no irreducible uniqueness)
  → NO  = PASS

CHECK 3: "Does the three_part_vulnerability_move require a SPECIFIC 
          memory from the coach's life?"
  → NO  = REJECT (vulnerability is performative, not real)
  → YES = PASS (first-party emotional data accessed)

CHECK 4: "Would the tribe react with 'How did you know that about me?'
          to at least one element of the content_premise?"
  → NO  = REJECT (no Recognition mode activated)
  → YES = PASS (specificity → universality bridge achieved)
```

**Axiom:** *A research finding's downstream value is proportional to its emotional specificity. Untyped findings force downstream agents to do the emotional work that research should have done.*

**Alchemy Grounding:**
- *"Prediction Error"* — TENSION findings document something that BREAKS the viewer's expectation
- *"Costly Signaling"* — VULNERABILITY findings document something EXPENSIVE to acknowledge
- *"Truth is recognized, not taught"* — RECOGNITION findings document something the tribe already KNOWS but has never seen articulated

**Mode Classification Protocol:**

#### Law 3: Depth Stratification, Not Breadth Accumulation

**Axiom:** *A research finding's creative power is proportional to its depth layer. Surface findings illustrate; mechanism findings explain; collision findings transform.*

**Alchemy Grounding:**
- *"Surprise requires understanding"* — only mechanism findings (L2) reveal the "why" that surprises. Only collision findings (L3) reveal the shadow
- *"The Shadow"* — L3 findings are the research equivalent of the Shadow: the contradictory truth that makes the story three-dimensional
- *"Meaning emerges from constraint"* — depth layers force the researcher to go BELOW the surface answer

**The 3-Layer Question Architecture:**

| Layer | Name | Question Type | What It Produces | Example (Witness Arc, HOOK Beat) |
|:---|:---|:---|:---|:---|
| **L1** | **Surface** | What exists? | Illustrative refs — images that SHOW | "Who are the wellness influencers this tribe follows?" → Profile photos, branded content |
| **L2** | **Mechanism** | Why does it work? | Explanatory refs — docs that REVEAL | "Why does this tribe trust naturopaths over doctors? What institutional failure drives this?" → Investigative journalism |
| **L3** | **Collision** | Where does it break? | Provocative refs — docs that CREATE TENSION | "Where have trusted wellness figures given advice later debunked? What's the cost of the trust the coach asks for?" → Fact-checks, counter-evidence |

**Depth Coverage Test (per beat):** At least 1 L2 and 1 L3 finding per beat. → If a beat has only L1 = visual story is illustrative but never surprising.

**Why L3 matters most:** L1 B-roll says *"here is the tribal world."* L2 says *"here is WHY it works this way."* L3 says *"here is where it contradicts itself."* Only L3 creates the visual prediction error that wakes the brain.

#### Law 4: The Narrative Provenance Gate

**Axiom:** *A research finding's value is inversely proportional to how discoverable it is without the coach's specific story.*

**Alchemy Grounding:**
- *"Scarcity is psychological, not physical"* — any AI can search "African wellness" and find beautiful imagery; true scarcity = findings that REQUIRE knowledge of this specific story
- *"Authenticity is non-negotiable"* — audiences detect whether visuals were assembled from generic research or deep story understanding
- *"Story is the vessel, not the decoration"* — findings are the EVIDENTIARY LAYER of the story, not decoration

**The 4 Provenance Checks:**

```
CHECK 1: "Could a researcher who never read the transcript find this?"
  → YES = REJECT (culturally valid but narratively disconnected)
  → NO  = PASS

CHECK 2: "Does this finding map to a SPECIFIC quote in the script?"
  → NO  = REJECT (thematic decoration, not evidence)
  → YES = PASS

CHECK 3: "If removed, would the beat's visual story lose something 
         irreplaceable?"
  → NO  = Supplementary, not structural
  → YES = PASS (load-bearing finding)

CHECK 4: "Does this finding create a DIFFERENT emotional response 
         from other findings for this beat?"
  → NO  = REJECT (emotional redundancy)
  → YES = PASS (layered emotional progression)
```

**Current gap the Provenance Gate fills:** The forbidden terms list catches generic *terms* (`"african woman"`, `"herbal tea"`). But a query like `"Kinkeliba traditional tea preparation"` passes the terms check while the returned image might be a magazine-spread stock photo usable in ANY African wellness video. The Provenance Gate tests whether the finding is **narratively load-bearing**, not just culturally specific.

A stream at one TTT level is emotionally monochrome — all confrontational OR all gentle — but a tool that modulates intensity doesn't structure function.

### The Design: 4 Laws of Voice Distillation

---

#### Law 1: Emotional Saturation Across Input Sources

**Axiom:** *A voice stream that draws from one emotional source produces monotone priming fuel. Authentic voice requires the COLLISION between what the coach believes, what the tribe feels, and what the research reveals.*

**Alchemy Grounding:**
- *"Surprise requires understanding"* — the most resonant SoC moment is where the coach's philosophy COLLIDES with the tribe's lived experience
- *"The Shadow"* — the SoC must contain the coach's shadow: where their certainty meets their doubt
- *"Vulnerability precedes connection"* — the SoC can't just SOUND vulnerable; it must contain ACTUAL vulnerability from `coach_soc_batch.md`

**Input Saturation Protocol:**

| Source | Saturation = | Failing = |
|:---|:---|:---|
| `soul_values.json` | Can state the coach's DECISIVE CLAIM for this topic in one sentence | Loaded file, can't articulate what coach BELIEVES about this content idea |
| `context_premise_spr.md` | Can state the UNNAMED FEELING the tribe has (not just the dimension label) | Identified "Fears + Insecurities" but can't describe the specific fear |

```
  → AI may CONTEXTUALIZE (place it in the stream)

STEP 4: Tag the source
```

#### Law 2: MODE as Emotional Constraint, Not Technical Routing

**Axiom:** *A visual's emotional impact is determined by whether every element serves ONE emotional function. Elements serving different functions cancel each other out.*

**Alchemy Grounding — the biological WHY:**

> *Cold lighting creates Tension because harsh contrast forces the viewer's visual system to work — high-contrast edges activate the amygdala's threat-detection pathway. The viewer's body responds to visual harshness AS IF the environment is hostile.*

> *Warm-intimate lighting creates Vulnerability because soft, close light mimics the conditions of physical proximity — candlelight, bedside, whispered conversation. The viewer's parasympathetic system activates, lowering defenses.*

> *Warm-expansive lighting creates Recognition because golden-hour light triggers nostalgia circuitry — the brain associates this specific color temperature (3200-4500K) with memories of belonging, sunset gatherings, shared meals.*

**MODE constrains every existing block:**

```markdown
=== PRIMAL ANALYSIS ===
MODE: TENSION (the viewer must feel that something is crushing her)
FEELING: The suffocating weight of pretending everything is fine...
BODY TRUTH: Fingers pressing into temples to hold skull together...
ENVIRONMENT: Her Caribbean kitchen before dawn. La Soufrière through window.
TIMESTAMP: "Je faisais tout bien... mais j'étais vide à l'intérieur." (02:34)
UNIQUENESS: Mahogany skin against blue pre-dawn light. Wedding ring loose.
```
